Privacy policy

Effective 15 November 2026. This notice describes the personal-use Ukraine OSINT Archive utility, its Google API access, and this public information website.

Who operates the utility

Ukraine OSINT Archive is maintained by an individual for private, non-commercial open-source research. The public operator contact is available through the operator's GitHub profile. It is not an official Google, GitHub, or Bellingcat product.

Information accessed

  • Google Sheets: a service account accesses a specifically shared archive queue, including submitted source URLs, processing statuses, metadata, archived links and cryptographic hashes when available.
  • Google Drive: a user-authorized OAuth connection requests the https://www.googleapis.com/auth/drive scope. This scope permits broad Drive file access; it is not technically restricted to the archive folder. The intended operation is saving and checking evidence files in the operator's designated private folder.
  • Source websites: Bellingcat Auto Archiver may access public posts, webpages, video/image content, timestamps, page text and source-specific metadata to make preservation copies.
  • GitHub: repository configuration and GitHub Actions process archive jobs; operational logs may include submitted URLs, status messages and non-secret diagnostic metadata.

Why and how information is used

Google user data is used solely to operate the user's requested archiving workflow: read the private source queue, save retrieved evidence to Google Drive, update status and source references, and verify saved files. It is not used for advertising, profiling, resale, or development of unrelated services.

OAuth tokens and service-account credentials are stored as encrypted GitHub Actions repository secrets and are materialized temporarily during a job. Archived evidence and queue records are not deliberately published by this website.

Storage, sharing and retention

Archive files and metadata are stored in the operator's Google Drive and Google Sheets accounts, under their sharing permissions. GitHub processes workflow code and retains job logs according to GitHub's applicable retention rules. Source websites and software dependencies necessarily receive ordinary network requests when material is fetched. There is no routine public disclosure or sale of Google user data.

The operator controls retention of archived files and queue records and may retain them until manually deleted. Deleting an item from one service does not automatically remove its copies from other services or existing provider logs.

Security and user control

The research repository and archive folder are private. Access credentials are not embedded in public website files. To stop future access, the operator can disable GitHub Actions jobs, revoke the Google OAuth grant in Google Account security settings, remove the service account's permission from the archive sheet, and delete or rotate stored GitHub Actions secrets.

Because the Drive OAuth scope is broad, the operator should only grant authorization after reviewing the consent screen and can revoke it at any time.

About this website

These static pages have no application login, analytics scripts, tracking pixels, forms, cookies set by site code or embedded archive content. GitHub Pages and the browser/network infrastructure may process normal access logs under their own policies.

Changes and inquiries

This policy may be updated if the archiving workflow or data practices change. The revision date will be updated on this page. For questions, contact the operator via the public GitHub profile.
