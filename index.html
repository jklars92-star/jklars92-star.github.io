Personal-use research infrastructure

Preserving online evidence for careful verification.

Ukraine OSINT Archive is a privately managed utility that helps its operator preserve publicly available web pages and media for open-source research. It uses Bellingcat Auto Archiver with Google Sheets as an archive queue and Google Drive for private evidence storage.

Information page only. This site is not a public search engine, does not host archived material, and does not provide third parties with access to the operator's Google Drive or research records.

1. Queue sources

The operator enters source URLs into a dedicated private Google Sheet. The archive queue is separate from other research trackers.

2. Preserve evidence

A private GitHub Actions workflow invokes Bellingcat Auto Archiver to retrieve supported public content, screenshots and relevant metadata.

3. Store privately

Captured files are stored in the operator's private Google Drive folder. The archive queue records statuses, source references and, when available, file links and hashes.

4. Review provenance

Saved material supports human source verification and comparison. Archiving a claim does not independently establish that the claim is true.

Google access and data practices

A service account is granted access to the dedicated archive spreadsheet. A separate user-authorized Google OAuth integration uses the broad Google Drive scope to create archive files. This scope is not restricted to the archive folder, even though that is the intended storage destination.

This website itself does not sign users in, request Google data, run analytics, or collect form submissions. Read the privacy policy for the complete disclosure of storage, permissions, retention and revocation.

Operator and project context

This is a non-commercial, single-user utility maintained for independent open-source research. It is not affiliated with Google, GitHub or Bellingcat.

For a general inquiry, see the operator's public GitHub profile. No private repository, credential file or archived evidence is linked here.
